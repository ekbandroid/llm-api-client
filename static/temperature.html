Один запрос при разной температуре

Каждая температура прогоняется несколько раз: по одному ответу разнообразие измерить не с чем. Thinking выключен, чтобы рассуждение не сглаживало влияние параметра.

Для каких задач какая температура

0 — низкая
Извлечение фактов, классификация, разбор текста в структуру, генерация кода, любые задачи с единственным правильным ответом. Там, где ответ должен воспроизводиться: тесты, кэширование, сверка результатов между запусками.
0.7 — средняя
Разговор, объяснения, переписывание текста, черновики. Формулировки живые, но модель не уходит от сути. Разумное значение по умолчанию, когда не понятно, что выбрать.
1.2 — высокая
Мозговой штурм, названия и слоганы, варианты сюжета — всё, где нужен перебор непохожих вариантов, а не один точный. Цена — растущий риск выдумок: факты при высокой температуре проверять обязательно.
Температура 0 не гарантирует одинаковый ответ. Она убирает случайность выбора токена, но не устраняет расхождения на стороне провайдера — на длинных ответах выборки при 0 расходятся, что видно в таблице выше.
